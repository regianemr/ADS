# 📚 Aulas de ADS
 
Repositório com os exemplos e exercícios que desenvolvo nas aulas do curso de **Análise e Desenvolvimento de Sistemas** na UniAmérica. Serve como registro da minha evolução e como material de consulta para estudos futuros.
 
## 📁 O que você encontra aqui
 
Cada pasta reúne os códigos de uma disciplina, organizados por aula.
 
 
## ▶️ Como usar
 
```bash
git clone https://github.com/regianemr/[nome-do-repositorio].git
cd [nome-do-repositorio]
```
 
Abra a pasta da aula que quiser e execute o arquivo principal.
